# The Witcher: Chronicles Before the Wild Hunt

The complete story of *The Witcher* (2007) and *The Witcher 2: Assassins of Kings*, told as an illustrated chronicle for players about to begin *The Witcher 3*.

**Live site:** https://cap-rehan.github.io/kaer-morhen-chronicles/

Spoilers for both games, by design.

## Run locally

Static site, no build step:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Editing

All story text lives in `js/data.js`; `js/app.js` only renders it.
